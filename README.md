# 🏎️ F1 — Beyond the Cockpit

An interactive fan website celebrating **Max Verstappen**, combining a cinematic 3D car experience with career milestones, championship achievements and season statistics.

### ✨ Features

- Scroll-controlled, textured Red Bull RB22 with cockpit close-ups
- “SIMPLY LOVELY” displayed on the steering-wheel dashboard
- Career milestones with photographs, a glowing lion and four glittering stars
- Season selection from 2015–2026 with statistics and expandable race results
- Red Bull garage wall design and locally hosted motorsport-style typography
- Responsive layouts, reduced-motion support and static fallbacks
- Secondary driver archive

### 🛠️ Built With

Vite · Vanilla JavaScript · Three.js · GSAP ScrollTrigger · HTML · CSS

### 🚀 Run Locally

Requires **Node.js 22.12 or newer**.

```bash
npm ci
npm run dev
```

Open the local URL printed in the terminal. On Windows PowerShell, use `npm.cmd` if `npm` is blocked by execution policy.

### ✅ Test and Build

```bash
npm run check
npm test
npm run build
```

The production build is generated in `dist/`. The development camera-review page is available at `/qa/car-review.html`.

### 📊 Data and Testing

Season data is a dated snapshot verified on **31 October 2026**. The 2026 season is incomplete; results are not updated live.

The approved source passed **50 automated tests**, syntax checks and the production build. Actual GPU visuals and physical-phone performance remain unverified in the development environment.
